## 🎯 1. วัตถุประสงค์และเป้าหมาย (Objective)
1. **ค้นหาไวติดสปีด (Sub-5ms Search Response):** ค้นหาข้อความ ยอดเงิน เลขบัญชี หรือชื่อบุคคลในแชท 500–1,000 ภาพ ได้ทันทีที่พิมพ์ (Instant Keystroke Search) โดยไม่กระตุก
2. **ไม่ต้องพึ่งพาเซิร์ฟเวอร์ (Zero-Server Dependency):** ประมวลผลการค้นหาในเบราว์เซอร์ของผู้ใช้ทั้งหมด (Client-Side Pure JS/WASM)
3. **กระโดดไปยังพิกัดเป้าหมายทันที (Direct Focal Jump):** ผลการค้นหาจะลิงก์ตรงกับพิกัด Bounding Box ทำให้คลิกคำค้นแล้วพาหน้าจอเลื่อนไปครอบบับเบิ้ลนั้นทันที

---

## 🔍 2. สถาปัตยกรรมดัชนีคำค้น (Inverted Index Architecture)

```
[ข้อความ OCR ทั้งหมด]
        │
        ▼
[ตัวตัดคำ & สกัดคีย์เวิร์ด (Tokenizer)]
        │
        ▼
┌────────────────────────────────────────────────────────┐
│  ตารางดัชนีผกผันขนาดจิ๋ว (Inverted Index Table)         │
├───────────────┬────────────────────────────────────────┤
│ คำค้น (Token) │ ตำแหน่งที่พบ (Image ID, Bubble ID, Y) │
├───────────────┼────────────────────────────────────────┤
│ "2000"        │ [Node-001, Img-8, Y: 1450]             │
│ "โอน"         │ [Node-001, Node-004, Node-012]         │
│ "ค่าครีม"     │ [Node-001, Img-8, Y: 1420]             │
└───────────────┴────────────────────────────────────────┘
```

### ฟีเจอร์หลักในการค้นหา:
1. **ตัวแยกประเภทข้อมูลอัจฉริยะ (Smart Entity Extractor):**
   * ตรวจจับตัวเลขยอดเงิน (เช่น `2000`, `2,000`, `2000.-`) ให้ค้นเจอได้ด้วยคำค้นเดียว
   * ตรวจจับเลขบัญชีธนาคาร (มีขีดหรือไม่มีขีด)
   * ตรวจจับวันเวลา (เช่น `13:53`, `บ่ายโมงห้าสิบสาม`)
2. **ระบบไฮไลต์ผลลัพธ์ (Instant Highlighting):** ไฮไลต์คำที่ตรงกันบนแถบรายการ และวาดกรอบสีส้มรอบคำบนหน้าจอรีวิวแชททันที
3. **ขนาดไฟล์เล็กมาก (Ultra-compact Size):** ตารางดัชนีของแชท 500 ภาพ มีขนาดเพียง 50–100 KB เท่านั้น
