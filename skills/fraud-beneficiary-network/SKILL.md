# 🕸️ FRAUD BENEFICIARY NETWORK SYSTEM
## สกิลวิเคราะห์และทำแผนผังเครือข่ายบัญชีผู้รับโอนเงินและผู้รับผลประโยชน์ (เรื่องที่ ๒)

> **Core Purpose:**  
> ใช้สำหรับสกัด วิเคราะห์ และสร้างแผนผังเครือข่ายความสัมพันธ์ทางการเงิน (Financial Network Graph) จากสลิปโอนเงินทั้งหมด จำแนกกลุ่มบุคคลออกเป็นเป้าหมายแท้จริง (Strike Targets) และคัดกรองกลุ่มบัญชีสั่งโอนแทน/เจ้าหนี้นอกระบบ (Proxy Beneficiaries) ออกได้อย่างแม่นยำ พร้อมสร้างแดชบอร์ดระบบเว็บแอปพลิเคชันแบบ Standalone 1-Click

---

### 🎯 1. เกณฑ์การจัดหมวดหมู่บุคคลแห่งคดี (Forensic Categorization Protocol)
1. **กลุ่มบุคคลเป้าหมายแท้จริง (Core Strike Targets - 100% Focus):**
   - **ตัวการหลัก (Main Defendant):** ผู้กู้ยืม, ผู้หลอกลวง, ผู้รับโอนตรงต่อเนื่อง
   - **ตัวการร่วม/ผู้สั่งการ (Coconspirators):** รุ่นพี่, ผู้ให้เลขบัญชีรับเงินกู้พร้อมสัญญาผลตอบแทนเกินอัตรา
   - **เครือข่ายฟอกเงิน/บัญชีม้าเครือญาติ (Family Mule Accounts):** พี่สาว, น้องสาว, ญาติที่รับเงินโอนกระจายทรัพย์สิน
   - **บัญชีนอมินีสวมชื่อพ้อง (Name-Spoofing Nominees):** บัญชีที่ชื่อตัวเหมือนกันแต่อำพรางนามสกุล
2. **กลุ่มบัญชีสั่งโอนจ่ายแทน (Proxy Beneficiaries - Disregard / Exclude):**
   - เจ้าหนี้นอกระบบ, ร้านค้า, บุคคลภายนอกที่จำเลยบงการให้โอนชำระหนี้แทน (ตัดออกจากสารบบดำเนินคดีหลักเพื่อไม่ให้สำนวนสับสน)

---

### 💻 2. ผลลัพธ์และระบบซอฟต์แวร์ที่ต้องสร้าง
- **Interactive Graph Dashboard:** ไฟล์ HTML แบบ Standalone (D3.js / Force-Directed Graph) ปรับขยายและคลิกดูสลิปประกอบได้
- **Thumbnail Generator:** แปลงสลิปหลักฐานเป็น WebP/JPG ขนาดกะทัดรัดสำหรับแสดงผลในระบบ
- **Beneficiary Summary Table:** ตารางสรุปรายชื่อ, ธนาคาร, เลขบัญชี, ยอดเงินรวม, จำนวนครั้ง, และบทบาททางกฎหมาย
- **1-Click Batch Launcher:** สร้างไฟล์ `.bat` สำหรับเปิดระบบด้วยเบราว์เซอร์ในคลิกเดียว
