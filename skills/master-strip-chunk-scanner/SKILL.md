# 📜 MASTER STRIP CHUNK SCANNER
## สกิลประมวลผลและสแกนภาพแคปจอยาวต่อเนื่องแบบ Multi-threading

> **Core Purpose:**  
> ใช้สำหรับประมวลผลภาพแคปหน้าจอแชทที่มีขนาดยาวต่อเนื่องเป็นพิเศษ (Continuous Scrolling Screenshots ความสูงเกิน ๕,๐๐๐ – ๑๐,๐๐๐ พิกเซล) ซึ่งระบบ OCR ปกติมักติดปัญหาความจำล้น (Decompression Bomb) หรืออ่านช้า โดยทำการซอยภาพออกเป็นบล็อกย่อย (Chunking) แล้วส่งประมวลผลแบบขนานหลายเธรด (Multi-threaded Parallel OCR) และตรวจจับความเชื่อมโยงของข้อความต่อเนื่องข้ามภาพ

---

### ⚙️ 1. สถาปัตยกรรม Chunking & Multi-threading
1. **Vertical Slicing Protocol (การซอยบล็อกแนวดิ่ง):**
   - กำหนดความสูงของบล็อก `chunk_height = 2000 px`
   - กำหนดระยะเหลื่อมซ้อน `overlap_step = 100 px` (เพื่อไม่ให้ข้อความหรือสลิปที่อยู่รอยต่อถูกตัดขาด)
2. **Dynamic Scaling Optimization (การปรับสเกลเพื่อ OCR ภาษาไทย):**
   - ปรับสเกลความกว้างเป็น `900 px` เสมอ (รักษา Aspect Ratio) ซึ่งเป็นขนาดที่ให้ความเร็วและความแม่นยำสูงสุดในการถอดรหัสฟอนต์ LINE ภาษาไทย
3. **Multi-Threaded Execution (รันขนาน ๘ คอร์):**
   - ใช้ `concurrent.futures.ThreadPoolExecutor(max_workers=8)`
   - สแกนจับคู่คีย์เวิร์ดบุคคลเป้าหมาย, เลขที่บัญชี, สลิปโอนเงิน, และยอดเงินอัตโนมัติ
4. **Consecutive Coordinate Detection (การตรวจจับเหตุการณ์ต่อเนื่องข้ามภาพ):**
   - เชื่อมโยงบริบทระหว่างภาพที่ N กับภาพที่ N+1 เช่น ในภาพที่ 41 มีการส่งเลขบัญชีรุ่นพี่ตัวการ และในภาพที่ 42 มีการส่งเลขบัญชีคู่พี่น้องในครอบครัว

### 📑 2. ผลลัพธ์ที่ได้
- ฐานข้อมูล JSON รายการที่ตรวจพบพร้อมพิกัดและขนาดภาพ
- ดัชนีภาพที่เข้าข่ายพยานหลักฐานจุดตายคดี (Smoking Gun Detection)
- สถิติความถี่การเอ่ยถึงเลขบัญชีและบุคคลเป้าหมาย
