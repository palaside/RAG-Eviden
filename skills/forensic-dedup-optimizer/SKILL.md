# 🧹 FORENSIC DEDUP OPTIMIZER
## สกิลตรวจจับและกำจัดไฟล์ซ้ำระดับไบนารีแฮช มาตรฐานศาล

> **Core Purpose:**  
> ใช้สำหรับตรวจสอบ เปรียบเทียบ และกำจัดไฟล์พยานหลักฐานที่ซ้ำซ้อน (Duplicate Artifacts) ในระดับไบนารีแฮช (MD5 / SHA-256) ป้องกันปัญหาการนับยอดเงินซ้ำซ้อน (Double-Counting) และตัดความเสี่ยงที่ทนายฝ่ายจำเลยจะยกข้อคัดค้านในศาลเรื่องการส่งเอกสารซ้ำซ้อนหรือเบิ้ลยอดเงินความเสียหาย พร้อมคืนพื้นที่จัดเก็บบนฮาร์ดดิสก์อย่างปลอดภัย 100%

---

### 🔬 1. สถาปัตยกรรมและกระบวนการทำงาน (4-Stage Deduplication Protocol)
1. **Stage 1: Binary Hash Generation (สร้างฐานข้อมูลแฮช)**
   - อ่านและคำนวณค่า MD5 และ SHA-256 ของไฟล์ภาพทุกไฟล์ในโฟลเดอร์เป้าหมาย
   - จับคู่ขนาดไฟล์ (Bytes) และมิติภาพ (Width x Height) เพื่อตรวจสอบความเหมือนสมบูรณ์
2. **Stage 2: Prefix & Pattern Matching (ตรวจจับแพตเทิร์นไฟล์สำเนา)**
   - ตรวจจับไฟล์ที่มีคำนำหน้า เช่น `dup_`, `copy_`, `(1)`, `(2)` ที่เกิดจากการคัดลอกซ้ำ
   - จับคู่ตรวจสอบกับไฟล์ต้นฉบับว่ามีไฟล์หลักอยู่จริงก่อนดำเนินการเสมอ
3. **Stage 3: Safe Verified Removal (การกำจัดแบบตรวจสอบย้อนกลับได้)**
   - ลบเฉพาะไฟล์สำเนาที่ได้รับการยืนยันว่ามีไฟล์ต้นฉบับอยู่ครบถ้วน 100%
   - คำนวณยอดพื้นที่ว่าง (Freed Bytes/MB) ที่ได้คืนกลับมา
4. **Stage 4: Court-Ready Audit Log (การออกบันทึกการตรวจพิสูจน์)**
   - บันทึกประวัติการทำลายไฟล์สำเนาเป็น Audit Log เพื่อใช้แสดงต่อศาลว่าเป็นการคลีนอัปเชิงเทคนิค มิใช่การทำลายพยานหลักฐาน

### 💻 2. แนวทางการเขียนโค้ดและเครื่องมือ
- ใช้ Python โมดูล `hashlib`, `os`, `pathlib`
- ตรวจสอบ `orig in all_files` ก่อนสั่ง `os.remove()` เสมอ
- ห้ามลบไฟล์ที่ไม่มีคู่แฝดต้นฉบับเด็ดขาด
