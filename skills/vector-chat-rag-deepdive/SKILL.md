# 🧠 VECTOR CHAT RAG DEEP DIVE
## สกิลเจาะลึกสืบค้นบริบทแชทและถอดรหัสนิติวิทยาศาสตร์ทางภาษา (เรื่องที่ ๓)

> **Core Purpose:**  
> ใช้สำหรับขุดค้นข้อความแชท (Chat Bubbles) จากฐานข้อมูลดัชนี Vector Embeddings (ไฟล์ `.jsonl`) และบันทึกแชทเรียงเวลา (Master Transcript) เพื่อค้นหาความเชื่อมโยงระหว่างคำพูดหลอกลวง เหตุการณ์ฉุกเฉิน ยอดเงิน และภาพสลิปพยานหลักฐานจุดตายคดี (Smoking Guns)

---

### 🔬 1. เสาหลักการวิเคราะห์นิติวิทยาศาสตร์ทางภาษา (Forensic Linguistics)
1. **การถอดรหัสกลอุบายจิตวิทยา (Psychological Traps):**
   - กลอุบาย Foot-in-the-door (เริ่มจากสต็อกสินค้า/ยอดเล็ก)
   - กลอุบายดึงบุคคลที่สามมาบีบคั้น (Emotional Coercion เช่น อ้างรุ่นพี่โทรมาร้องไห้)
   - กลอุบายล่อลวงด้วยผลตอบแทนระยะสั้น (Ponzi-style baiting สัญญาคืนพร้อมกำไรใน ๒๔ ชม.)
   - กลอุบายผลัดผ่อนด้วยความเท็จ (อ้างกู้เงินธนาคารผ่านแล้ว, เงินเดือนติด, ป่วยฉุกเฉิน)
2. **การจับคู่กับโหนดเวกเตอร์ (Vector Node Cross-Referencing):**
   - ทุกข้อความสำคัญต้องมีรหัส `Event ID`, วันที่, เวลา, ผู้ส่ง, ยอดเงิน, และชื่อไฟล์ภาพหลักฐานอ้างอิงชัดเจน

---

### 📑 2. ผลลัพธ์ที่ต้องส่งมอบ
- **Vector Search Engine:** สคริปต์ค้นหาคำสำคัญและชื่อเป้าหมายแบบ Semantic / Keyword RAG
- **Chat Context Dossier:** เอกสารสรุปคำพูดสำคัญเรียงตามกลุ่มบุคคลเป้าหมาย
- **Smoking Gun Catalog:** แคตตาล็อกภาพแคปแชทและสลิปที่มัดตัวจำเลยแบบปฏิเสธไม่ได้
